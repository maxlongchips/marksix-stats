# 排除号码逐期历史记录 — 设计

**意图 / 为什么**：用户要在「下期排除参考」里监测每一期预测号码的准确率，需要一个逐期历史记录，而非只有右侧的总回测汇总。

**目标**：新增一个可折叠的「逐期历史记录」区块，全量回测（第 51 期到最新一期），每期一行展示预测、实际开出、结果与累计成功率，顶部汇总总成功率。

**非目标**：不做本地持久化（预测可精确重算）；不改预测算法；不改成实时推送。

**方案（已选）**：全量回测 —— 用纯函数重算每一期的预测，立即得到全部历史数据，开奖同步进新一期后自动补行。

**关键决定**：
- 「成功」= 全部候选号码都未出现在当期 7 个号码中（与现有 `backtestExclusions` 一致）。
- 每行额外显示实际出现了几个（0 = ✓，1~5 = ✗ 并标出命中号码）。
- 表格跟随上方 5/7/12 数量选择切换；默认最新一期在最上面，超过高度内部滚动。

**改动文件**：`stats.mjs`（新增 `exclusionHistory`）、`app.mjs`（新增 `renderHistory`）、`index.html`（区块 + 样式），最后重跑 `build-static.mjs` 生成 `client.js`。
